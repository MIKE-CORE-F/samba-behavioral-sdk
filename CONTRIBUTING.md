# Contributing to S.A.N.B.A. Behavioral SDK

Thank you for your interest in contributing to the **S.A.N.B.A. Behavioral SDK**! We appreciate community involvement to help improve the adapters, core engine interfaces, and overall integration capabilities.

Please follow these guidelines to ensure a smooth contribution process.

---

## 🔒 Scope & Security
* **Public Scope:** This repository contains strictly the public SDK layer, adapters, and C++ interface headers. 
* **Proprietary Core:** Core operating system kernels, internal proprietary daemons, and confidential internal libraries remain strictly private and closed-source. Pull requests targeting internal or proprietary architecture will not be accepted.
* **Security Issues:** If you discover a security vulnerability, please do not open a public issue. Instead, report it privately through our designated security channels.

---
